# dev-helper 🛠️

一个轻量、高效的开发者命令行工具箱（CLI Tool），旨在提升日常开发效率，内置版本检查、时间戳转换、IP 地址查询等实用功能。

---

## ✨ 核心功能

* ⏰ **时间戳转换**：支持 Unix 时间戳（秒/毫秒）与人类可读日期格式的双向快捷转换。
* 🌐 **IP 地址查询**：快速获取当前本机及公网 IP 的详细网络与地理位置信息。
* 🔍 **版本检查**：检测当前工具及相关开发环境依赖的版本状态。
* 🧪 **自动化测试保障**：内置完整的单元测试套件，保障命令行交互的稳定性。
